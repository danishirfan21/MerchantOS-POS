Source evidence: POS `b7ce8f3e`, run 41375166591, `accessibility.json` at each viewport. Darken only these existing text tones within the established palette; remove whole-card opacity for unavailable products so text retains contrast. The browser scan now gates serious/critical tagged findings and retains manual-review items. A further scan found the selected category count badge at 4.35:1; its existing green background was darkened. No accessibility certification is claimed.

A first fix run caught a focus-restoration regression after applying inert background semantics and a test selector matching a newly introduced hidden heading before logout completed. Both were corrected before acceptance. These are implementation regressions, not invented baseline product defects.

The first added Admin test accidentally inherited a shared API session, invalidating later test contexts; explicit empty storage state isolates the cashier. The initial scanner injection was correctly rejected by CSP; a same-origin test-only route fixes the scanner without weakening CSP. These are test-harness issues, not product defects or reasons to remove existing tests.

Exploration covers empty search, repeated clicks, canceled payment, keyboard focus/wrap, reload during uncertainty, real committed-response loss, API/DB outage (separate infrastructure drill), stale manager stock after a cashier transaction, small viewports, Arabic, session/logout and filter/pagination. Actual screenshot review supplements assertions. No external human UAT is claimed. Backend financial formulas, inventory concurrency and reporting formulas are unchanged.

R04 Medium — the new blank MFA and mobile Overview/Orders scans measured white button text at 3.76:1 and green link text at 3.6:1. Evidence: Admin `ea1221ed`, run 41375955548. Darken only existing auth/mobile emerald text/button shades from #059669 to #047857; preserve layout, hierarchy and mandatory MFA. Existing responsive/MFA cases plus tagged axe checks guard the correction.

The first launcher verification redirected initializer masking commands into a private log; the artifact audit correctly blocked that log from upload. Initialization now streams its mask registrations directly to the CI runner, and only safe launcher-result JSON is included in artifacts. The credential audit is preserved.

The first real browser DB-outage fixture used Docker stop against an auto-remove disposable container; Docker correctly removed it, so the restart attempt failed and later cases could not connect. The fixture now pauses/resumes PostgreSQL, preserving its process/data while making the real database unavailable, with guaranteed cleanup and bounded CI-only connection/command timeouts. No application or security assertion is removed.
